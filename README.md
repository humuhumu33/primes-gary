## Important Notes for LLMs

- **Images:** The original site contained ~148 diagrams and photos. The actual image files are *not* in this archive. Every broken image reference has been replaced with a descriptive text block. A complete catalog with descriptions exists in `02-MEDIA/IMAGES.md`.
- **Cross-links:** Internal links have been rewritten to point to local Markdown files where possible. Some links to pages not archived (e.g., "About the Author") still point to the live site.
- **Data files:** Spreadsheets and PDFs in `03-DATA/` and `04-PAPERS/` are binary assets. See the respective READMEs for descriptions.
- **HTML Archive:** `01-HTML-ARCHIVE/` contains unmodified HTML snapshots for reference. They are not the canonical reading format.
