# Data Spreadsheets

These are binary Excel files (.xls / .xlsx) containing computed factorization data. They are not directly readable by text-based LLMs, but their contents are described below for context.

| File | Description |
|------|-------------|
| `spreadsheets/89_Squared_First_1000_Primes.xlsx` | 89 squared times the first 1000 primes |
| `spreadsheets/Digital_Factorization_Roots_24x24_Matrix.xlsx` | 24×24 digital root factorization matrix |
| `spreadsheets/DupeAnalysis.xls` | Duplicate analysis within factorization sets |
| `spreadsheets/Factorization_10000.xls` | Factorization data up to 10,000 |
| `spreadsheets/Factorization_Computation_Method_Zero_to_10000.xlsx` | Computation method factorization 0–10,000 |
| `spreadsheets/Factorization_Dyads_Modulo_90_Congruency.xlsx` | Factorization dyads grouped by modulo 90 congruency |

> **Tip:** If you need the raw numbers from these spreadsheets, ask to extract them with a Python script (pandas/openpyxl) or use `ssconvert`/`libreoffice` to convert to CSV.
